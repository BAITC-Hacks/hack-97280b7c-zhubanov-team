# Установка командных инструкций Codex

Командные инструкции и навык HackAlem Logistics из архива сохранены в этом репозитории. Навык применим, когда команда получит официальный текст логистического кейса и критерии оценки.

## Перед началом работы

1. Получите официальный кейс, приложения, данные и критерии оценки.
2. Прочитайте все материалы и составьте таблицу требований с источником, обязательностью, доказательством для демо и неясностями.
3. Выберите один подтверждённый процесс. Не предполагайте тарифы, координаты, ёмкость, сроки или доступность.
4. Назначьте владельцев папок и API-контракта в соответствии с `AGENTS.md`.
5. Работайте в отдельной ветке и отправляйте изменения через pull request.

Командные инструкции намеренно не выбирают стек, API-контракт или требования кейса без официальных материалов.
